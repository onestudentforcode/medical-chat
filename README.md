# 智能医疗问答助手

基于循证医学的专业用药咨询系统

## 在线访问

演示地址：https://your-username.github.io/medical-chat/

## 主要功能

- 智能问答：自然语言交互，解答用药疑问
- 循证医学：基于权威指南和专家共识
- 证据等级：清晰标注证据来源和可信度
- 安全警示：自动识别风险并提供警告
- 响应式设计：支持手机、平板、电脑访问

## 快速开始

### 本地运行

```bash
python -m http.server 8080
```

或使用提供的脚本：
```bash
start_server.bat
```

访问 http://localhost:8080

## 部署到 GitHub Pages

1. 在 GitHub 创建新仓库
2. 上传 index.html 文件
3. 在 Settings > Pages 中启用
4. 等待 1-2 分钟即可访问

详细指南请查看 GITHUB_PAGES_GUIDE.md
